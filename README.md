# OpenMQVPNRouter

MQVPN クライアント (マルチWAN対応 ルーター)

# 概要

実機ルーター PC に NixOS を焼いて導入する構成と、MQVPN サーバーを OCI コンテナで動かす構成の両方を扱う。
詳細な導入手順は以下の各 howto を参照。

- ルーターのビルド・導入: [docs/howto-router.md](docs/howto-router.md)
- サーバー（OCI コンテナ）の構築: [docs/howto-server.md](docs/howto-server.md)
- テスト環境（ラボ / 4VM）: [docs/howto-lab.md](docs/howto-lab.md)
